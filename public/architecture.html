1. High-Level Technical Architecture

Dobby is built as a cloud-native, modern full-stack web application designed for zero-friction household task and schedule automation. It uses a single-container Express + Vite hybrid deployment model running behind Google Cloud Run.

2. How the AI Extraction Engine Works

Dobby does not merely "summarize" text. It acts as an Unstructured-to-Structured Cognitive Pipeline that converts messy real-world household data (school permission slips, doctor appointment texts, messy WhatsApp group chats, utility bills) into actionable tasks with absolute dates, times, assignees, and reminders.

Step-by-Step AI Execution Lifecycle

1

Multimodal Ingestion & Triage (Client + Server)

Users can submit raw text, paste screenshots via Ctrl+V, or drag and drop up to 10 files simultaneously (PNG, JPEG, PDF, DOCX, TXT, CSV). Multer parses the multipart request into memory buffers without disk latency.

2

Document Deconstruction & Text Normalization

The backend inspects MIME types:

  • DOCX Files: Parsed server-side using mammoth.js to extract clean raw text hierarchies.
  • Plain Text / CSV: Decoded directly from binary buffers.
  • Images & PDFs: Encoded into Base64 inlineData payloads for direct visual parsing by Gemini.
3

Temporal & Contextual Grounding Prompt Construction

Before dispatching to Gemini, the system injects critical runtime ground truth into the system prompt:

  • currentNow: ISO timestamp representing the user's exact current moment (e.g. 2026-09-12T07:43:00Z).
  • userTimeZone: Resolves "tomorrow at 3 PM" to the user's actual timezone (e.g., Asia/Kolkata, America/New_York).
  • knownMembers: Known family member names and UUIDs so Gemini can accurately assign the task to "Mom", "Sarah", or "Alex".
4

Gemini Model Invocation with Structured JSON Mode

The engine calls the Google GenAI SDK (@google/genai) using strict JSON output mode (responseMimeType: 'application/json').

5

Transient Resilience & Cascading Fallback

If the primary model experiences high load (HTTP 503, 429), Dobby automatically retries and cascades through alternative models:

gemini-3.8-flash → gemini-flash-latest → gemini-3.1-flash-lite → Deterministic Regex Parser.
6

Interactive Review & Human-in-the-Loop Confirmation

Extracted suggestions are returned with a confidence score (0.0 - 1.0), source excerpt quote, and original relative time expression. The user can adjust title, date, priority, or assigned member before 1-click committing to the database.

AI Prompt Contract (Low-Level Schema)

The prompt forces the Gemini model to respond exclusively in this typed JSON structure:

[
  {
    "title": "Pay Electricity Bill",
    "description": "Account #90218, total $142.50 due before cutoff",
    "dueDate": "2026-09-18",
    "dueTime": "17:00",
    "priority": "high",
    "assignedToName": "Sarah",
    "confidence": 0.98,
    "sourceExcerpt": "[invoice.pdf] Total due: $142.50 by Friday 5:00 PM",
    "originalExpression": "by Friday 5:00 PM",
    "warnings": []
  }
]

3. Low-Level Subsystem Architecture

Core Backend Components & Responsibilities

Subsystem Source File Technical Responsibilities
Server Entry & Ingress server.ts Boots Express on port 3000, mounts Vite dev middleware in dev, serves production assets from /dist, initializes background reminder interval.
Cognitive AI Service server/services/gemini.ts Handles GoogleGenAI client singleton, multi-file buffering, mammoth docx conversion, fallback regex extraction, and candidate model cascade.
Database Layer server/db.ts Dual storage pattern. Manages Mongoose ODM connections to MongoDB Atlas with auto-reconnect, and maintains a local JSON fallback in /data/*.json.
Reminder Daemon server/services/reminderScheduler.ts Runs every 60 seconds. Queries findDueReminders(nowIso), atomically transitions status to fired, writes in-app alerts, and triggers webhook dispatch.
WhatsApp & Alert Dispatcher server/services/notifier.ts Dispatches alerts across WhatsApp (Twilio / Custom Webhook), Push, and In-App delivery channels. Logs delivery status in audit collections.
REST Routing Layer server/routes/*.ts Modular Express routers: auth.ts (JWT), tasks.ts (CRUD & filters), reminders.ts (schedule & snooze), ingest.ts (AI endpoints).

Database & Data Models

Entities are modeled with Mongoose schemas and duplicated in TypeScript interfaces:

  • Users: Name, Email, PasswordHash, WhatsApp Phone, Timezone, Notification Preferences.
  • Groups: Name, Type (Family, Project), Members with Role (Admin/Member), Invite Codes.
  • Tasks: Title, Description, DueDate, DueTime, Priority, Status (pending, completed, dismissed), AssignedTo, AI Metadata (sourceExcerpt, confidence).
  • Reminders: TaskId, DueDateTime (ISO), NotificationChannel (WhatsApp, in-app), Status (scheduled, fired, dismissed).
  • DeliveryLogs: Timestamp, Recipient, Channel, Payload, Status (sent, failed).

4. Security & Deployment Specification

  • Zero Secret Exposure: All Gemini API keys, MongoDB credentials, and JWT secrets remain strictly in backend environment variables (process.env) and are never exposed to the client bundle.
  • Container Ingress: The container runs on Linux with 0.0.0.0:3000 binding, fronted by Google Cloud Run with autoscaling (0 to N instances) and Google-managed TLS certificates.
  • Resilient Offline/Cold Start: If MongoDB Atlas network access is blocked or unconfigured, the app falls back seamlessly to the local basin, allowing users to test without server crashes.
